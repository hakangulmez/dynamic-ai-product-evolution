# Frontier Capability Assessor Skill

## Purpose

Assess dated frontier task replicability.

## Required reading

- `SPEC-014`
- `SPEC-015`
- `FRONTIER_BASELINE_POLICY.md`

## Procedure

1. Load eligible frontier baseline.
2. Assess core deliverable and completeness.
3. Assess tools/data and switching friction.
4. Return ordinal and components.

## Output discipline

- Use the governing schema.
- Cite source and passage IDs.
- Preserve unknowns and ambiguity.
- Write concise audit rationales, not hidden chain-of-thought.
- Produce a run manifest.

## Stop conditions

- Baseline contains post-cutoff capabilities.
- Task customer need is missing.
