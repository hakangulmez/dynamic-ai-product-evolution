# Task Extractor Skill

## Purpose

Extract and consolidate customer-facing tasks from validated capabilities.

## Required reading

- `SPEC-009`
- `SPEC-010`
- `EXTRACTION_METHODOLOGY.md`

## Procedure

1. Extract capabilities.
2. Generate high-recall task candidates.
3. Write independent customer needs.
4. Consolidate by economic separability.
5. Validate evidence and ambiguity.

## Output discipline

- Use the governing schema.
- Cite source and passage IDs.
- Preserve unknowns and ambiguity.
- Write concise audit rationales, not hidden chain-of-thought.
- Produce a run manifest.

## Stop conditions

- Product or capability identity is unresolved.
- Evidence does not describe a customer action.
