# Longitudinal Task Matcher Skill

## Purpose

Link task observations across adjacent periods.

## Required reading

- `SPEC-012`
- `SPEC-013`
- `LONGITUDINAL_TASK_MATCHING.md`

## Procedure

1. Generate candidate predecessor links.
2. Compare customer need and deliverable.
3. Classify transition.
4. Preserve split/merge and uncertainty.

## Output discipline

- Use the governing schema.
- Cite source and passage IDs.
- Preserve unknowns and ambiguity.
- Write concise audit rationales, not hidden chain-of-thought.
- Produce a run manifest.

## Stop conditions

- Source coverage is too incomplete to infer discontinuation.
