# Source Discovery Skill

## Purpose

Discover official dated sources for one firm and observation window.

## Required reading

- `SPEC-002`
- `SPEC-004`
- `SOURCE_POLICY.md`
- `TEMPORAL_POLICY.md`

## Procedure

1. Resolve official domains and CIK.
2. Enumerate SEC forms and exhibits.
3. Enumerate official IR, product, docs, release-note, pricing, and archive sources.
4. Classify dates and source roles.
5. Write coverage gaps and rejected candidates.

## Output discipline

- Use the governing schema.
- Cite source and passage IDs.
- Preserve unknowns and ambiguity.
- Write concise audit rationales, not hidden chain-of-thought.
- Produce a run manifest.

## Stop conditions

- A source domain cannot be verified as official.
- Publication date is unresolved for a historically critical page.
