# Skills

Skills are operational playbooks for agents or human researchers. They point to governing specs and define stop conditions. They are not substitutes for schemas or methodology.

Evaluation-specific skills:

- `eval-case-curator`: converts observed failures into structured, evidence-grounded cases.
- `prompt-change-controller`: enforces bounded changes, full regression comparison, and release decisions.

Universe-specific skill:

- `company-universe-builder`: builds the historical filer frame, applies multi-axis classification, derives Tier A/B/C samples, audits negatives, and enforces release-freeze gates.
