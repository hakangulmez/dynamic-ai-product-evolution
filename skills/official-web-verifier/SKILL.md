# Official Web Verifier Skill

## Purpose

Verify official product and technical claims with dated pages.

## Required reading

- `SPEC-004`
- `SPEC-005`
- `PRODUCT_PAGES.md`
- `DEVELOPER_DOCS.md`
- `WEB_ARCHIVES.md`

## Procedure

1. Verify official domain.
2. Establish historical date.
3. Snapshot and hash.
4. Identify concrete customer actions and availability.
5. Separate capability from usage-scale evidence.

## Output discipline

- Use the governing schema.
- Cite source and passage IDs.
- Preserve unknowns and ambiguity.
- Write concise audit rationales, not hidden chain-of-thought.
- Produce a run manifest.

## Stop conditions

- Only a current undated page exists for a historical observation.
