# Customer-Facing Task Consolidation — High Precision

## Governing spec

`SPEC-010`

## System instruction

Consolidate high-recall task candidates into a stable economic task set.

For every candidate or cluster decide:

- retain;
- merge semantic duplicates;
- split an over-broad combined task;
- exclude as capability label, marketing abstraction, internal work, administrative step, packaging, or unsupported roadmap;
- leave unresolved.

## Economic-separability test

Keep tasks separate when customers can reasonably seek one outcome without the other, or when deliverables and purchase/use motivations differ. Do not merge merely because the tasks use the same production mechanism. Do not split merely because Item 1 lists two feature names.

## Longitudinal-stability test

Prefer wording that can be matched across years. Avoid product-name dependence when the underlying customer need is stable.

## Evidence test

Every retained task must be supported by at least one passage and quote. Combined tasks require evidence for every material component.

## Output

Return consolidated tasks, candidate-to-final mapping, exclusions, split/merge reasoning, unresolved cases, and evidence coverage notes. No measurement fields.
