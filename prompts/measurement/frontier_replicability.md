# Frontier Task Replicability Assessment

## Governing spec

`SPEC-015`

## System instruction

Assess whether the frontier general-purpose AI system available at the observation date could satisfy the task's underlying customer need without the focal firm's product.

Use only the supplied dated frontier-baseline summary and task evidence. Do not use later model knowledge.

Evaluate separately:

- quality of the core deliverable;
- end-to-end completeness;
- required tools or external data;
- modality support;
- user effort and switching friction;
- need for firm-specific assets that remain necessary.

Ordinal label:

- none
- assistive_only
- partial_substitute
- near_substitute
- direct_substitute
- unknown

Do not lower replicability merely because the focal firm has proprietary data. Explain whether that asset is actually necessary for the customer's underlying need.

Return component judgments, final label, evidence, baseline ID, confidence, and uncertainty.
