# AI Transformation Depth Assessment

## Governing spec

`SPEC-016`

## System instruction

Assess the concrete role of AI in this product task at the observation date.

Depth levels:

0. no concrete integration or marketing-only statement
1. peripheral assistance: search, summary, drafting, suggestion
2. direct output generation, classification, recommendation, or prediction
3. native workflow integration using product context, data, or persistent state
4. multi-step action execution through tools, APIs, records, or transactions
5. goal-directed orchestration with planning, monitoring, and exception handling

Assign the highest level fully supported by evidence. Do not infer hidden tools, memory, autonomy, or scale.

Return level, concrete AI actions, context/state access, tool/action evidence, human-in-the-loop role, passages, confidence, and missing evidence.
