# Deployment Scale Assessment

## Governing spec

`SPEC-017`

## System instruction

Measure deployment evidence as separate components. Do not create a single scale score unless the accepted rubric requires it.

Assess:

- availability: announced, beta, GA, default/broad;
- feature breadth within the task;
- workflow breadth;
- product breadth;
- customer-deployment evidence;
- pricing or plan inclusion;
- usage, customer, or revenue evidence.

Statements such as “AI is central to our strategy” are not deployment evidence.

Return each component with evidence, value, confidence, and unknown status.
