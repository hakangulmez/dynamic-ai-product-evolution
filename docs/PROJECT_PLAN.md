# Project Plan

The durable, versioned thesis plan lives in [planning/README.md](planning/README.md).

It is a navigation and decision-support layer, not an artefact authority. For a
claim about a production run, use the named `data/runs/...` manifest, its output
hashes, the applicable schema, and the committed source/ADR at the checked-out
revision. The planning pack records current direction, open choices, and the
reasoned order of work so that execution does not depend on a chat session.
